# OpenCode screens: implementation plan

Design source of truth: `design/opencode-screen/SPEC.md` (v0.2, approved) and the approved prototype `design/opencode-screen/prototype.html` + `oc-splash.js`.
Branch: `feat/opencode-screens`. Baseline: `pio run -d firmware -e waveshare_amoled_216` = 2,159,059 / 3,342,336 bytes flash (64.6%).

Repo rules that apply to every package (from `CLAUDE.md`):
- **No `#ifdef BOARD_*` in shared code.** Board differences come from `board_caps()` (`firmware/src/hal/board_caps.h`). `#ifdef BOARD_HAS_PSRAM` is the only sanctioned compile-time gate.
- **C6 boards have no PSRAM:** no new large buffers. Use only LVGL objects/labels plus the existing splash canvas.
- **LVGL 9 fonts must be patched** after `lv_font_conv` (`docs/fonts.md`), or they render invisible.
- Match the surrounding code style: comment density, naming (`snake_case` functions, module prefixes) and Arduino/LVGL idioms.
- Do not commit. Do not flash hardware. Do not touch the user's installed daemon or LaunchAgent.

## Interfaces (contracts; implement exactly)

### WP1: fonts and logo
- **Fonts:** IBM Plex Mono (SIL OFL 1.1, from https://github.com/IBM/plex).
  - LVGL 9 font symbols, 4 bpp: `font_plex_48` (Medium), `font_plex_40` (Medium), `font_plex_24` (Medium), `font_plex_18` (Regular), `font_plex_16` (Regular), `font_plex_12` (Regular).
  - Range `0x20-0x7E` plus `0xB7` (·) and `0x2026` (…), and `0x25CB` (○) if the TTF has it. If it doesn't, report it so the UI falls back to `o`.
  - Declare them in C with `LV_FONT_DECLARE(font_plex_48)` and so on.
- **`firmware/src/oc_logo.h`:** header-only, `static const` data like `logo.h`. It is generated by `tools/gen_oc_logo.js` from the pixel grids below (no SVG tools needed).

### WP3: `oc_splash.h` + splash.h additions
```c
// splash.h (added)
void splash_set_external(bool on);   // on: splash_tick() stops advancing Clawd and splash_show() does not pick; off: normal Clawd behaviour resumes
void splash_render_external(const uint8_t *cells, const uint16_t *palette); // 60*60 cell indices → RGB565 palette; draws through the same render path (PSRAM canvas and C6 strip blit)

// oc_splash.h
enum oc_mood_t { OC_MOOD_IDLE, OC_MOOD_ACTIVE, OC_MOOD_BUSY, OC_MOOD_NEAR, OC_MOOD_LIMITED };
void oc_splash_start(void);          // take over the shared splash canvas (splash_set_external(true)), restart the scene intro
void oc_splash_stop(void);           // splash_set_external(false)
void oc_splash_tick(void);           // call every loop; no-op unless started
void oc_splash_set_mood(oc_mood_t m);// auto scene: IDLE→typeon, others→scanner (unless a manual scene is set)
void oc_splash_next_scene(void);     // PWR: typeon → assemble → scanner → typeon (manual override)
void oc_splash_play_assemble(void);  // one-shot assemble (window reset), then back to auto scene
bool oc_splash_is_active(void);
```
Scene behaviour, timings, colours and the scanner frame table: `SPEC.md` §5 plus the reference implementation `design/opencode-screen/oc-splash.js` (port it; it is approved).

### WP4: `oc_data.h` + `ui_opencode.h`
```c
// oc_data.h
struct OcData {
    bool valid;          // false until first successful parse
    bool ok;
    char src[5];         // "api" | "est" | "none"
    int  p5, r5;         // 5h percent, minutes to reset (-1 = no active window)
    int  pw, rw;         // weekly
    int  pm, rm;         // monthly
    bool limited;        // "st":"limited"
    long t7;             // 7-day tokens, thousands
    long tk; float cd;   // src=="none": today tokens (thousands), today USD
    float c7;            // src=="none": 7-day USD
    char m[16]; int ms;  // top model (ASCII) + share %
    int  a; char ag[12]; long la;  // active sessions, agent, seconds since last activity
};
bool oc_is_payload(const char *json);             // cheap check: contains "k":"oc"
bool oc_parse(const char *json, OcData *out);     // ArduinoJson 7; false on error or k != "oc"

// ui_opencode.h
void oc_usage_init(lv_obj_t *parent);   // full-size container, hidden; layout from board_caps() (3 breakpoints: height>=460 L, >=300 M, else S)
void oc_usage_show(void);
void oc_usage_hide(void);
lv_obj_t *oc_usage_get_root(void);      // ui.cpp attaches the tap handler
void oc_usage_update(const OcData *d);  // stores a copy, stamps millis(), redraws
void oc_usage_set_ble(bool connected);
void oc_usage_tick(void);               // status blink, stale detection (OC_FRESH_MS 300000), "last activity" ageing
bool oc_has_data(void);                 // a valid payload has arrived since boot
```
Layout: `SPEC.md` Annex A. Wordmark widths follow the generated images (195/156/117, centred). The battery icon is **not** drawn here, because ui.cpp's existing battery widget stays visible on every non-splash screen.

### WP5: integration (ui.h / main.cpp)
- `screen_t`: `SCREEN_SPLASH, SCREEN_USAGE, SCREEN_OC_SPLASH, SCREEN_OC_USAGE, SCREEN_COUNT`.
- `void ui_next_screen(void); void ui_prev_screen(void);`. The cycle skips both OC screens while `!oc_has_data()`. The page indicator shows 4 or 2 dots (6 px, gap 8, centre y from Annex A) for 1.5 s after each change.
- `void ui_update_opencode(const OcData *d)`: calls `oc_usage_update`, maps the mood with the SPEC §5 rules, and calls `oc_splash_play_assemble()` when `p5` or `pw` drops by ≥5 points.
- **Buttons (main.cpp):**
  - PRIMARY/SECONDARY: tap < 300 ms = navigate. PRIMARY goes prev, or next when `button_count < 2`; SECONDARY goes next.
  - Holding ≥ 300 ms sends the HID key down (Space / Shift+Tab) until release.
  - Wake-swallow is unchanged.
- **Touch tap:** next screen.
- **PWR short:** on `SCREEN_SPLASH` → `splash_next()`; on `SCREEN_OC_SPLASH` → `oc_splash_next_scene()`; otherwise → `brightness_cycle()`. Pairing is unchanged.
- **RX routing:** `oc_is_payload()` → `oc_parse` → `ui_update_opencode` → ack/nack. The OC path never calls `parse_json`, `usage_rate_sample`, the chime or `ui_update`.
- **`ble.cpp`:** a 2-slot RX ring, so a second write doesn't overwrite an unread one.
- **Sim:**
  - `firmware/sim/scenario-opencode.jsonl`, with interleaved Claude and OC lines.
  - `SIM_START_SCREEN=splash|usage|oc_splash|oc_usage`, applied once the first payloads are in.
  - `SIM_W`/`SIM_H` are not needed. Add envs `sim_368` (368×448) and `sim_240` (240×240) that extend `sim` with `-DLCD_WIDTH/-DLCD_HEIGHT` overrides, making `boards/sim/board.h` use `#ifndef`.
